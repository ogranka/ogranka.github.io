# Портфолио: сайты и веб-сервисы под ключ

Проекты вместо списка технологий: каждый кейс открывается как страница
«задача, решение, что получил клиент, стек» с живой версией внутри. Сайт
собран на [Astro](https://astro.build): компонентная вёрстка, стили в SCSS,
интерактив на TypeScript, на выходе статические страницы без рантайм-фреймворка.

| Кейс | Что показывает |
|---|---|
| [Магазин букетов](https://ogranka-web.ru/cvety/) | Мобильная витрина: каталог с фильтром-шторкой, сборка букета, корзина, оформление заказа в четыре шага |
| [ИИ-консультант](https://ogranka-web.ru/assistant/) | Чат в магазине букетов: отвечает по каталогу и правилам доставки, стримит ответ, передаёт сложные вопросы флористу |
| [Городской журнал](https://ogranka-web.ru/zhurnal/) | Онлайн-издание о двух городах: лента, рубрики, статьи, авторы, поиск, RSS и карта сайта на коллекциях контента |
| [Сайт клиники: было и стало](https://ogranka-web.ru/before-after/) | Страница 2012 года и её современная версия под интерактивной шторкой |
| [Гонка скорости](https://ogranka-web.ru/speed-race/) | Тяжёлая сборка против лёгкой: живые счётчики загрузки |
| [Сайт форума](https://ogranka-web.ru/forum-hero/) | Первый экран уровня студийного сайта: canvas-анимация в 17 КБ |

Дизайн-система хаба: токены в `src/styles/base/_root.scss`, светлая и тёмная
тема (системная настройка плюс переключатель), переходы между страницами на
нативных view transitions, появление блоков через IntersectionObserver.
Магазин букетов живёт на `/cvety/shop/` со своей палитрой и шрифтами;
названия, цены и магазин «Пион и мята» вымышленные, фото с Unsplash
(источники в `src/assets/cvety/credits.md`). Чат консультанта в магазине ходит на отдельный сервер-прокси (код хранится вне этого репозитория), ключ доступа к нейросети в браузер не попадает. Журнал «Окрестности» собран
на коллекциях контента: статьи в `src/content/zhurnal/*.md`, справочники
городов, рубрик и авторов в `src/data/zhurnal.ts`, издание и города
вымышленные, фото с Unsplash (`src/assets/zhurnal/credits.md`).

## Структура

```
src/
├── pages/       страницы (каждая свой маршрут)
├── layouts/     базовый HTML-каркас
├── components/  переиспользуемые блоки
├── scripts/     интерактив (TypeScript)
├── styles/      SCSS: токены, база, партиалы компонентов
├── content/     статьи журнала (markdown, коллекция контента)
├── data/        данные кейсов и справочники
└── assets/      шрифты, фото, превью
```

## Разработка

```
npm install
npm run dev      # локальный сервер
npm run build    # статическая сборка в dist/
```

Деплой автоматически на GitHub Pages при пуше в `main`.
