# Портфолио: интерактивные кейсы

Живые демонстрации вместо списка технологий. Сайт собран на
[Astro](https://astro.build): компонентная вёрстка, стили в SCSS,
интерактив на TypeScript, на выходе — статические страницы без
рантайм-фреймворка.

| Кейс | Что показывает |
|---|---|
| [Было → стало](https://ogranka.github.io/before-after/) | Сайт 2012 года и его современная версия под интерактивной шторкой |
| [Гонка скорости](https://ogranka.github.io/speed-race/) | Тяжёлая сборка против лёгкой: живые счётчики загрузки |
| [Оживший первый экран](https://ogranka.github.io/forum-hero/) | Canvas-анимация уровня студийного сайта в 17 КБ |

## Структура

```
src/
├── pages/       страницы (каждая - свой маршрут)
├── layouts/     базовый HTML-каркас
├── components/  переиспользуемые блоки
├── scripts/     интерактив (TypeScript)
├── styles/      SCSS: токены, база, партиалы компонентов
└── assets/      иконки и изображения
```

## Разработка

```
npm install
npm run dev      # локальный сервер
npm run build    # статическая сборка в dist/
```

Деплой — автоматически на GitHub Pages при пуше в `main`.
